# .github

Org-wide defaults for all Internetworkexpert repositories: pull request template,
contributing guide, security policy, issue templates, and starter workflows.

Any repository in this organization that doesn't define its own version of these files
inherits the ones here automatically.

> **This repository is public** — GitHub requires that for org-wide inheritance of default
> community health files to work. Keep it to generic, non-sensitive defaults only.
> Internal documentation belongs in
> [`.github-private`](https://github.com/Internetworkexpert/.github-private) or Confluence.

## What lives here

| Path | Purpose |
|---|---|
| `PULL_REQUEST_TEMPLATE.md` | Default PR description for every repo without its own template |
| `CONTRIBUTING.md` | Branch model, branch naming, and commit conventions |
| `SECURITY.md` | How to report a security vulnerability |
| `.github/ISSUE_TEMPLATE/` | Default issue templates |
| `workflow-templates/` | Starter workflows offered in the Actions tab of org repos |
