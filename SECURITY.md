# Security Policy

## Reporting a vulnerability

Please **do not** report security vulnerabilities through public GitHub issues,
discussions, or pull requests.

If you believe you have found a security vulnerability in an INE repository or service,
contact us via [ine.com/contact-us](https://ine.com/contact-us) and ask for your report to
be routed to the security team. Please include a description of the issue, steps to
reproduce, and any affected URLs or repositories.

INE staff should report suspected vulnerabilities through internal channels instead.
